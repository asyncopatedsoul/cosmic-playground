# Playtest guide: local multiplayer (Windows, two gamepads)

Two players, one Windows PC, a game controller each, one shared world. It takes about **40 minutes**: 5 to set up, 25 to play, 10 for questions. Kids are welcome; the game is made for all ages.

## What you need

- A **Windows 10 or 11** PC or laptop. A TV over HDMI is great.
- **Two game controllers.** Xbox (wired, wireless adapter or Bluetooth) and PlayStation 4/5 (USB or Bluetooth) controllers are best; most others work too.
- Speakers or a TV. Both players listen to the same sound.
- A mouse is handy for the person helping, but nobody has to use it.

---

## Set up (5 minutes)

1. Install the Windows app from `{{ITCH_URL}}`: through the [itch app](https://itch.io/app) (recommended, it updates itself), or download the Windows zip, unzip it and run `Cosmic Playground.exe`. If Windows says *Windows protected your PC*, choose *More info → Run anyway*.
2. Connect both controllers **before** starting the game if you can. Check Windows sees them (*Settings → Bluetooth & devices*).
3. Start the game and click once inside the window so it has focus and the sound starts.
4. **The first controller player presses any button.** A ring in their colour appears with a **2** in it (the mouse is always player 1, even if nobody uses it). Then **the second controller player presses any button** and gets a **3**.
5. Check the build: **people** button (top) → bottom of the sheet shows `{{BUILD_ID}}`.

If a ring doesn't appear, press a button again and click the game window once. If the screen says *Click here to wake the controllers*, click it: Windows only lets the game read controllers while its window is in front.

## Controls (show the players this, or let them discover)

| Control | Does |
|---|---|
| Left stick | Move your ring |
| `A` / ✕ | Play the toy under your ring |
| Hold `A` on a toy's base | Pick it up and slide it |
| Hold `A` on a handle | Pull the handle |
| `RT` / `LT` (R2 / L2) | Stretch up / down |
| Right stick | On a toy: twist. On empty space: turn and zoom the camera |
| `X` / □ | Start / stop the toy's rhythm |
| `Y` / △ | Add a toy: `LB`/`RB` choose, `A` place |
| Hold `B` / ○ on a toy | Put it away |
| `View` (Create / Share) | Undo your last put-away |
| Hold `Menu` (Options) | Leave |

The full list is in the [player guide](USER-GUIDE.md#gamepad-new-in-this-build).

---

## Play (25 minutes)

Let the players lead. Some prompts if they run out of ideas:

1. Each player adds a toy and plays it.
2. Make one toy play a rhythm on its own (`X`), then make a second one play along.
3. Build a little band of six toys together.
4. Try to both grab the same toy. What happens?
5. Put a toy away and bring it back (`View`).
6. One player leaves (hold `Menu`) and joins again (press a button).

---

## For the facilitator

Watch quietly and note:

| Watch for | Note |
|---|---|
| Joining | Did each player find "press any button" without being told? Seconds until their ring appeared |
| First minute | Did they find their ring? First thing they tried |
| Camera | How often did one player move the camera while the other was busy? Did it cause arguments? |
| Adding toys | Did they find `Y`? Did the picker make sense? |
| Help | Every "how do I…?" question, word for word |
| Conflicts | Grabbing the same toy, putting away the other's toy |
| Technical | Controller dropped, sound glitches, slow frames, the focus banner |

---

## After the session

Ask both players (kids can answer out loud; write it down):

1. What was the best thing you made?
2. Was anything hard to do with the controller?
3. Did you ever lose track of which ring was yours?
4. Did sharing the camera get in the way?
5. Would you want to play this again together?

Then send `{{FEEDBACK_CONTACT}}`: the answers, your observation notes, the controllers you used (brand and how connected), the PC model, and the build id. If you can, include **people → Details** (it lists the controllers the game saw).

## Trouble

| Problem | Try |
|---|---|
| A controller does nothing | Press a button on it; click the window; unplug and replug |
| Both controllers are the same player | Tell us which controllers; try one wired and one wireless |
| *Click here to wake the controllers* | Click it; avoid alt-tabbing during play |
| No sound | Click in the world once; check the 🔇 button and Windows volume |
| More than four controllers | Windows supports four Xbox-style controllers at once |

Thank you for testing!
